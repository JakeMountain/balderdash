# Bluff Dictionary

A Balderdash variant with a word list chosen so funny bluffs don't stand out.

- `SPEC.md`: the design
- `CLAUDE.md`: build order and conventions, written for Claude Code
- `data/starter-words.md`: 255 words you can play with tonight
- `pipeline/`: the Jev-based word pipeline; `python pipeline/pilot.py` runs the pilot
