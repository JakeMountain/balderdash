# Bluff Dictionary

A Balderdash variant with a word list chosen so funny bluffs don't stand out.

- **[Browse the words](https://jakemountain.github.io/balderdash/)**: draw a word, guess, then reveal the definition and its Jev scores
- `data/words.json`: the word list the game plays
- `SPEC.md`: the design
- `pipeline/`: the Jev-based pipeline that finds and scores the words
- `game/`: the phone game (Cloudflare Worker + React)
- `CLAUDE.md`: layout, commands and conventions, written for Claude Code
